# Deeb Andrawis — Portfolio

Personal portfolio site for Deeb Andrawis, Senior Automation Developer.

Built with plain HTML, CSS and JavaScript — no build step, deployed via GitHub Pages.

## Structure

- `index.html` — page markup
- `assets/css/styles.css` — styles (light/dark theme)
- `assets/js/main.js` — nav, accordion, filters, theme toggle, contact form

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.
